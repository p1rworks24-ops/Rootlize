Privacy Policy

Last updated: September 1, 2026

This page describes how the current Rootlize Prototype Preview handles data. Rootlize is preview software. This behavior can change.

Your image library stays on this PC

Rootlize is not a cloud photo library. It does not upload, copy, or move your local image collection to Rootlize cloud storage. You point the app at folders already on this PC. Those image files remain in the folders you choose. You do not have to import them into a separate Rootlize library.

Creating an optional account does not turn your folders into a cloud photo library.

What runs locally

These features run on this PC:

  • Basic Search (filename, tags, and text found in images)
  • OCR
  • Local ranking used by Meaning Search

Local search index data stays on this PC. You do not download a separate search model.

Cloud AI features

Ask AI uses an external AI service. It needs the internet and your agreement before it runs. You do not need a Rootlize account to try the public Prototype, including Prototype AI within the usage limit.

The first time you open Ask AI, Rootlize shows a consent screen. Until you agree, Rootlize does not start sending images for AI analysis. After you agree, the first analysis may send image contents and related request data to an external AI service. Rootlize then saves facts from that analysis. Later Meaning Search uses those saved facts and does not resend images on every search.

Prototype AI usage is limited. After you reach the limit, local search, tags, favorites, folder operations, and other non-AI features still work. Rootlize does not keep your image library in Rootlize cloud storage.

Accounts are optional

The public Prototype does not require sign-up or login. You can start as a guest. If you choose to sign in, Rootlize uses Supabase for account identity. You can sign in with Google, GitHub, or email.

If you use Google or GitHub, that provider authenticates you and Supabase receives the account identity needed to sign you in. An optional account is for your Rootlize identity. It does not upload your image files.

Usage metadata

Rootlize keeps usage metadata so it can enforce AI usage limits. That metadata can include operation type, counts, model, token or cost totals, status, and timestamps.

Usage telemetry does not store:

  • query text
  • filenames
  • local file paths
  • image bytes
  • OCR text
  • facts JSON
  • API keys

This applies to local usage telemetry and cloud usage events used for AI limits.

Account and optional Prototype data

Depending on how you use the Prototype, Rootlize may also keep:

  • account identity and display name
  • a device record for this PC
  • plan / AI entitlement and usage-limit status
  • optional Prototype feedback answers, app version, and session identifiers, if you submit feedback

Prototype feedback does not include query text, image files, paths, or facts.

Data stored on this PC

The app stores local app data on this PC. That can include settings, the local search index, local usage telemetry, workflow data, and other app files. Sign-in credentials are stored on this PC in the Windows Credential Manager.

The app may also write diagnostic logs on this PC. Those local logs are separate from usage telemetry.

This website

rootlize.com is a static marketing site. It does not receive your image library. The site may load fonts from Google Fonts and check GitHub for the current download.

Changes

Rootlize is a Prototype. Features, providers, limits, and this policy may change. This page describes current behavior. It is not a promise that future versions will work the same way.
