What you can do

Find. Narrow. Act. Automate.

Rootlize is the workspace for files already on your PC — not another cloud library.

  1. Find

    Search a large local folder and pull out the images you need.

  2. date tag 20 8 3

    Narrow

    Filter a large set down to the few that still matter.

  3. sunset IMG_1042
    DSC_019.png notes.png

    Act

    Tag, favorite, rename, and move — on the files you just found.

  4. Search Select Action

    Automate

    Connect the steps once, then run the same work again.

On your PC

Use the folder you already have.
