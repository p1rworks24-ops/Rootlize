What you can do

Find. Organize. Automate.

Rootlize is a local workspace for images already on your PC — search, then keep going.

  1. Find

    Search filenames and text in the folder you already have, use Meaning Search for what an image shows, or Ask AI in natural language.

  2. sunset IMG_1042
    DSC_019.png notes.png

    Organize

    Tag, favorite, rename, and move the images you just found. Search results are a starting point, not a dead end.

  3. Select Search Action

    Automate

    Save Select, Search, and Action as a Workflow. Run it again when the same work comes back — Rootlize still asks you to confirm first.

On your PC

Use the folder you already have.

Point Rootlize at an existing Windows folder. Your images stay there. You do not move them into a Rootlize cloud library.

This PC
Ask AI

Stays on this PC

Rootlize works with folders you already have. It does not upload your image library to Rootlize cloud storage, and you do not have to import files into a separate app library.

needed AI only

AI is opt-in

Ask AI asks for consent first. Until you agree, Rootlize does not start sending images for AI analysis. After you agree, the first analysis may send images to an external AI. Saved facts are reused, so Meaning Search does not resend images every time. Prototype AI usage is limited; local search and organize still work after the limit.
