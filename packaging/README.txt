Rootlize - Prototype Preview
Your Local Workspace.
Find, organize, and work with the images on your PC — without moving them to the cloud.
Version: v0.1.0-preview
Platform: Windows 10 / Windows 11 (64-bit)

This README ships with the v0.1.0-preview portable ZIP.

HOW TO START
1. Extract this ZIP completely. Do not run Rootlize.exe from inside the ZIP.
2. Open the extracted Rootlize folder.
3. Run Rootlize.exe.

Keep Rootlize.exe and the _internal folder together. Do not delete or move _internal.
Python or other development tools are not required.

CURRENT FLOW
1. After first launch, continue as Guest. Sign-in is not required.
2. Choose an existing local folder that contains images.
3. Find images with Basic Search or Ask AI.
4. Preview, organize, and act on what you find.
5. Guest users can use Prototype AI, within the usage limit.
6. Save a repeated flow as Automation.

Your images stay on this PC. Rootlize does not move the library to the cloud.
Basic Search and local search run on this PC. No extra model setup.

ASK AI
The first time you use Ask AI, a consent screen is shown. Images are not sent
to an external AI before you agree. After consent, the first analysis may send
images to an external AI. Later Meaning Search uses saved facts and does not
send images on every search.

Ask AI has a usage limit. After you reach the limit, local search, tags, folder
operations, and other non-AI features still work.

SECURITY
This build is unsigned. Windows SmartScreen or Defender may show a warning.
Continue only if you obtained this ZIP from a trusted official source, then
choose More info → Run anyway (Japanese Windows: 詳細情報 → 実行).
Do not continue if the download source is unknown.

KNOWN LIMITATIONS
- Prototype Preview; features may change
- Windows 10 / 11 64-bit only
- Portable ZIP; no installer, automatic update, or code signing
