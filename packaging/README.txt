Capixe - Prototype Preview
Capture less. Find more.
Version: v0.1.0-preview
Platform: Windows 10 / Windows 11 (64-bit)

HOW TO START
1. Extract this ZIP completely.
2. Open the Capixe folder.
3. Run Capixe.exe.

Keep Capixe.exe and the _internal folder together. This is a portable preview build; Python is not required.

CURRENT FLOW
1. Choose an Images folder.
2. Select Analyze to index PNG files locally.
3. Search by filename or text visible inside an image.

DATA
- Settings: %APPDATA%\Capixe
- Image-analysis index: %LOCALAPPDATA%\Capixe
- Default screenshot root: %USERPROFILE%\Pictures\Capixe

SECURITY
This build is unsigned. Windows SmartScreen or Defender may show a warning. Only run it if you trust the source and verified the download. Image analysis runs locally; screenshots are not uploaded to a Capixe cloud service.

KNOWN LIMITATIONS
- Prototype Preview; features may change
- Windows only; PNG analysis only
- No installer, automatic update, or code signing
