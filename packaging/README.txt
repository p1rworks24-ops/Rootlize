Rootlize - Prototype Preview
Your Local Workspace.
Find, organize, and work with the images on your PC — without moving them to the cloud.
Version: v0.1.0-preview
Platform: Windows 10 / Windows 11 (64-bit)

This README ships with the v0.1.0-preview ZIP.

HOW TO START
1. Extract this ZIP completely.
2. Open the Rootlize folder.
3. Run Rootlize.exe.

Keep Rootlize.exe and the _internal folder together. This is a portable preview build; Python is not required.

CURRENT FLOW
1. Sign in to start.
2. Choose an existing local image folder.
3. Find images with Basic Search or Meaning Search.
4. Preview, organize, and act on what you find.
5. Ask AI when you want help in your own words.
6. Save a repeated flow as Automation.

Your images stay on this PC. Rootlize does not move the library to the cloud.
Basic Search, OCR, and bundled Meaning Search run locally. No extra model setup.
Ask AI needs sign-in and the internet after you agree.

DATA
- Settings: %APPDATA%\Capixe
- Local index and logs: %LOCALAPPDATA%\Capixe
- Default screenshot root: %USERPROFILE%\Pictures\Capixe

SECURITY
This build is unsigned. Windows SmartScreen or Defender may show a warning. Only run it if you trust the source and verified the download. Sign-in is for your Rootlize account. Your image files remain on this PC. Ask AI uses an external AI service after you agree.

KNOWN LIMITATIONS
- Prototype Preview; features may change
- Windows only
- No installer, automatic update, or code signing
